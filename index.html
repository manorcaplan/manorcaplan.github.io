03 / CHECKOUT

购买流程与优惠码

这份搬瓦工购买教程按订单流程整理。开始前准备好常用邮箱，并留意结算页面显示的具体选项。

  1. 01

    选择方案

    从资源需求和预算出发，进入对应套餐的选购页面。

  2. 02

    确认机房与付款周期

    查看可选数据中心、线路说明和账单周期，再点击 Add to Cart 加入购物车。

  3. 03

    填写账户信息

    进入 Checkout，按页面要求填写姓名、邮箱、密码及账单信息；也可以先注册账户。

  4. 04

    检查订单并付款

    核对配置、金额、续费周期及服务条款。参考资料提到支付宝和 PayPal 等方式，具体以结算页面显示为准。

PROMOTIONAL CODE

优惠码如何核验？

参考资料将 BWHCGLUKKB 和 NODESEEK2026 标记为已失效，属于历史状态，不代表当前有可用优惠。

如有其他优惠码，可在购物车的 Promotional Code 栏输入并点击 Validate Code；确认验证结果及订单金额后再付款。没有优惠码也可以留空继续。

04 / AFTER PURCHASE

购买后与
常见问题

留意账户和开通邮件，按邮件与账户页面的指引登录控制面板。重装系统或更换配置前，先备份数据并确认操作可能带来的影响。

所有机房都有 CN2 GIA 吗？

不是。不同系列和机房的线路不同，请查看具体套餐的机房特性说明，并结合访客所在地与运营商测试。

优惠码验证失败怎么办？

检查输入是否有多余空格，确认代码是否过期以及是否适用于所选套餐。验证结果和最终金额以购物车显示为准。

应该选择月付还是年付？

先确认该方案提供哪些周期，再比较每个周期的总金额和续费安排。选择与你的使用计划和预算相符的周期。
